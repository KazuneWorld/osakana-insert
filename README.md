# おさかなINSERT

サカナクションのチケット抽選応募フォームへの入力を補助するChrome拡張機能です。
あらかじめ保存しておいた応募者・同行者の情報を、ワンクリックでフォームに自動入力できます。
また、おまけとしてチケット詳細ページに入ると表示される案内ポップアップを自動的に非表示にする機能も備えています！

## 主な機能

- 応募者・同行者の情報（ID、パスワード、電話番号など）をブラウザ内に保存
- 「⚡フォームに入力する⚡」ボタン1つで、応募ページに自動入力
- ※おまけ チケット詳細ページに入ると表示される案内ポップアップを自動非表示

## 使い方

1. このリポジトリを ZIP でダウンロードし、任意の場所に解凍する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」から、解凍したフォルダを選択する

5. 該当する公演の応募ページを開き、拡張機能アイコンをクリックして「おさかなINSERT」を開く
6. 各項目を入力して「保存する」をクリック
7. 「⚡フォームに入力する⚡」をクリックすると、保存した内容が入力される

## 注意事項

- **本ツールは入力の手間を省くためのものであり、抽選結果や当選確率に影響を与えるものではありません。**
- 入力されたデータはお使いの端末のローカル上（ Chrome の `chrome.storage.local` ）にのみ保存され、外部サーバーへの送信は一切行いません。
- 自動入力後は、実際のページの入力内容が正しいか必ずご自身で確認してから送信してください。

- 対象サイトの仕様変更により、予告なく動作しなくなる場合があります。
